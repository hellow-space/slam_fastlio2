# /path 最小有界发布方案及验证

用户要求分析方案并做最小修改。生产代码仅修改 LIVMapper.h/.cpp：

1. 保留现有 nav_msgs::Path 容器，追加前移除最老项，最多保留 2000 个位姿。
2. 每个定位周期仍记录最新位姿；steady_clock 控制最多每秒发布一次，首次立即发布。
3. /path 外层 header.stamp 与最新位姿一致；诊断 path_publish.status=0 表示只维护历史，
   status=1 表示实际发布。其他消息的时间戳不变。

不新增线程、节点、定时器或配置参数；TF/odom 的发布调用、定位数学、传感器队列和 QoS 不变。
两个常量是本次最小方案的工程起点，不是官方规定。10 Hz 下 RViz 看到约最近 200 秒轨迹，
以约 1 Hz 刷新；并非每秒只保存一个点。需要完整轨迹时记录 odom，离线生成。

沿用 vector 可减少改动。删除最老项会移动最多 2000 个元素，这个成本有固定上限，
而不是随着总运行时长增长；若未来需要更大窗口，再考虑环形容器。

## 验证计划

- 修改前版本使用回退头文件及 liblaser_mapping 编译同一集成探针。
  实际调用 LIVMapper::publish_path；超过 2000 项应触发回归失败，作为 RED。
- 修改后实际方法接收 75000 次位姿更新，验证最多 2000 项、保留最新项且顺序正确；
  实际 ROS 订阅验证 header、频率与消息长度，作为 GREEN。
- 预填 74000 个历史位姿，以 10 Hz 调用相同方法，比较修改前后函数耗时和实际输出大小。
  这是合成历史压力测试，不把结果等同于原现场 DDS/RViz 负载。
- 编译诊断 ON/OFF，并用同一份原始 IMU/LiDAR bag 在隔离域 176 回放，
  验证原始输入数量、TF/odom 输出及数值一致性。测试不启动导航。
- 保留旧二进制、源码及原 Log；只更新独立计时安装，原普通安装保留。

本修复消除 /path 历史无限增长这一条已证实的过载来源；其他阶段是否超预算，
仍以 full_cycle、真实状态年龄和 LiDAR 队列增长判断。

证据目录：/home/nvidia/fastlivo_timing/path_bound_ab_20261115_01/。

## 实测结果（2026-11-15）

- 诊断 ON/OFF 均编译通过；已有记录器测试 3/3 通过。
- 修改前实际方法在第 2001 次更新后超过容量，回归检查按预期失败（RED）。
- 修改后实际方法连续接收 75000 次合成位姿更新，长度始终不超过 2000，
  最终保留最新 2000 项、顺序正确，消息 header 等于最新项时间戳。
- 集成订阅收到 13 个有界快照，最小 header 间隔约 1.00002 秒（GREEN）。
  这是加速的合成输入测试，不是连续两小时实机运行。

预填 74000 项、以约 10 Hz 调用实际发布函数的合成压力对照：

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 函数每次调用平均耗时 | 153.926 ms | 0.695 ms |
| 函数每次调用最大耗时 | 158.978 ms | 8.666 ms |
| 实际发布调用平均耗时 | 153.919 ms | 6.647 ms |
| 最终历史长度 | 74031 | 2000 |
| 订阅收到的消息数 | 31 | 4 |

“每次调用”平均值包含修改后未到发布时间的快返回，不能解读为每次发送只需 0.695 ms。
新版本压力测试的最大值还包含首次清理人工预填的 74000 项历史；正常启动的历史不会超过 2000。
该测试使用同进程实际 ROS 订阅和本机回环传输，不把其耗时当作现场 RViz/DDS 负载的精确重现。

原始 26 秒 IMU/LiDAR bag 回放对照：

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| IMU 收到数 | 5224 | 5224 |
| LiDAR 收到数 | 262 | 262 |
| TF / odom 收到数 | 258 / 258 | 258 / 258 |
| /path 收到数 | 258 | 25 |
| 完整成功周期平均 | 55.258 ms | 55.245 ms |
| path_publish 每次调用平均 | 0.284 ms | 0.029 ms |

两版 TF/odom 父子坐标系一致，同时间戳的位姿分量最大差约 2.22e-16。
短 bag 尚未积累大量历史，因此完整周期平均基本不变；本修复针对长时历史增长，
不能用短 bag 声称室外故障或所有过载来源已经消失。
